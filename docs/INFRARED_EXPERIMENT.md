# 红外图像模型：内部测试与跨来源检验

当前模型是研发基线，**不能用于生产自动告警**。内部测试看似可用，但不调阈值直接迁移到另一套公开数据时几乎把所有正常图像报为异常。这里保留失败结果，作为后续模型与数据选择的基准。

## 数据与评测约束

- 训练来源：[Raptor Maps InfraredSolarModules](https://github.com/RaptorMaps/InfraredSolarModules)，约 2 万张 24×40 的 8 位灰度组件裁图、12 类。去掉无法解码文件后为 19,988 张；按解码后完全相同的像素分组，再划分训练 11,992、验证 3,998、测试 3,998 张。没有可核实的场站或航次标识，因此这个测试**不是跨场站测试**；近似重复图像也未完全排除。
- 外部来源：[sUAS Infrared PV Fault Classification](https://zenodo.org/records/20860870)，3,675 张来自**同一正射影像**的灰度裁图；文件 MD5 为 `9f8a4dc88a5e1474cdd30697079286bf`。其中 8 号目录为正常 2,835 张，1–7 号目录合计故障 840 张。它的故障分类与 Raptor Maps 的 11 种异常分类不同，因此这里只比较**正常/异常二分类**，不把类别名当作互通。
- 模型、训练配方、集成成员都只根据 Raptor Maps 验证集选定。二分类阈值也先在该验证集固定，然后**一次性**评估 sUAS；不使用 sUAS 调参。sUAS 图像缩放至 24×40，并采用 Raptor Maps 训练集的均值、标准差。

## A10G 训练与内部结果

自主实现的三层卷积分类网络约 85.6 万参数。比较随机初始化与用本数据**训练分区全部图像**做随机遮挡重建预训练，均以 3 个种子训练并在验证集按宏平均 F1 选择。预训练不是外部大模型权重，也不能称为跨场站预训练。训练配置：最多 40 轮遮挡重建、80 轮监督训练，早停耐心 12，批量 256；完整逐轮记录及权重在本地 `reports/infrared_raptor_a10_v1/`，不提交仓库。

| 配方 | 三个种子验证宏平均 F1 | 平均 |
| --- | --- | ---: |
| 随机初始化 | 0.6654 / 0.6719 / 0.6593 | 0.6655 |
| 遮挡预训练后微调 | 0.6704 / 0.6667 / 0.6678 | **0.6683** |

平均增益只有 **0.0028**，且只有两个种子提高，不能认为预训练有稳定优势。按预定规则选中预训练配方的三种子平均概率集成，验证宏平均 F1 为 **0.6915**。选定后读取一次内部测试集：12 类准确率 **0.8352**，宏平均 F1 **0.7060**。类别差异很大：`No-Anomaly` F1 为 **0.9430**，`Soiling` 仅 **0.2857**。不能用总体准确率掩盖弱类。

## 一次性外部迁移

在 Raptor Maps 验证集上，以 `1 − P(No-Anomaly)` 做异常分数，二分类 AP **0.9876**，选定阈值 **0.5150**，验证宏平均 F1 **0.9497**。固定模型和阈值后，sUAS 的结果为：

| sUAS 指标 | 结果 |
| --- | ---: |
| 二分类 AP / ROC AUC | 0.5989 / 0.7289 |
| 固定阈值宏平均 F1 | **0.1984** |
| 故障召回率 / 精确率 | 839/840 = 0.9988 / 839/3642 = 0.2304 |
| 正常误报 | **2803/2835 = 98.9%** |

模型把绝大多数 sUAS 图像都视为异常，包括正常图像；这种阈值迁移不可用。该结果也**不能单独归因于网络结构**：两套数据的采集、图像归一化、空间尺度和异常定义不同；两者都不是可校准温度的辐射测量输入。sUAS 只有一张正射影像，不能据此估计多场站性能。完整外部报告在本地 `reports/infrared_suas_transfer_v1.json`。

## 下一步模型选择

先固定多来源、按场站/航次隔离的验证协议，再比较当前 CNN、公开预训练视觉骨干微调、跨域归一化与阈值校准。模型选择应同时约束异常召回和正常误报；若缺少独立场站，明确标记为研究性结果。不要在这套已经查看的 sUAS 数据上反复挑模型再称其为盲测。真实部署还需要辐射测温、飞行与设备元数据、现场复核标签及新场站试运行。

复现训练与外部评估入口：`src/prepare_infrared.py`、`src/train_infrared.py`、`src/evaluate_suas_ir_transfer.py`。外部评估脚本会校验 sUAS 压缩包 MD5。
