# 模型实验记录模板

复制本文件填写。可公开的精简记录放 `benchmarks/`，完整日志与检查点放忽略的产物目录或团队存储。不要填写服务器密码、令牌或不允许公开的数据。

## 基本信息

- 实验编号／日期：
- 负责人／关联 Issue 或 PR：
- 代码提交 SHA；若有未提交改动，附补丁或记录源码校验值：
- 研究问题；预期验证的改进：
- 状态：计划中／运行中／完成／失败／中止（只选实际状态）

## 数据和划分

- 原始来源、版本、许可及本地清单位置：
- 输入文件 SHA256：
- 任务、字段／图像类型、单位、时区、标签来源和类别映射：
- 训练／验证／测试的样本数、各类数量：
- 原始时间范围或行边界；分组键、去重规则、边界隔离和窗口定义：
- 训练期间使用哪些数据做归一化、预训练和增强：
- 测试集是否在此前开发中被查看过：
- 无法核实的设备／事件／组件来源及泄漏风险：

## 模型和环境

- 架构、参数量、输入输出形状：
- 从零训练或预训练来源；第三方代码／权重的许可和引用：
- 对照基线和消融配置：
- Python、PyTorch、CUDA、驱动、GPU 型号／数量；依赖清单路径：
- 种子、批大小、优化器、学习率、训练轮次、早停和模型选择指标：
- 阈值／集成成员如何确定，使用了哪个数据分区：
