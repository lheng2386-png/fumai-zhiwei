# 前端原型验收记录

日期：2026-10-18（北京时间）。本次仅验证前端样例流程，不运行后端训练，也不宣称模型效果。

## 已通过

- Node.js 对 `dist/app.js`、`dist/data.js`、`serve.mjs` 的语法检查。
- 本机 Microsoft Edge 155 无界面浏览器检查，桌面 1440×1000、移动 390×844。
- 概览正常加载，4 项指标、24 台设备及本地静态资源正常显示；日/周/月示意曲线与悬浮提示切换。
- 事件按复核状态、证据、设备、关键词组合筛选；无匹配时显示空状态；清除筛选恢复全部 12 条样例。
- 设备视图筛选 3 台候选关注设备；点击设备进入对应事件；全局搜索定位事件。
- 事件详情展示功率、连续采样、同群及逐点证据；Escape 关闭。
- 复核依据必填，保存后待复核数更新；刷新保留记录；重复修改追加历史。
- 人工说明中的 HTML 保持为文本，不创建可执行元素。
- CSV 成功下载，标识样例来源，包含预置样例与全部本机追加历史，并转义公式前缀。
- 五个视图在手机宽度下不造成整页横向溢出；宽表格在独立容器内滚动；移动导航可展开、跳转、关闭。
- 浏览器控制台与 JavaScript 运行时错误为零。

## 可复核步骤

1. 按 README 启动，打开概览，切换日/周/月趋势。
2. 进入异常事件：状态选“待复核”，证据选“单机偏离同群”，设备选 `inv_07`，应有 1 条匹配。输入不存在的关键词应出现空状态，清除筛选恢复 12 条。
3. 打开 `DEMO-2107-002`；清空说明并保存，应提示填写依据。填写说明后保存，刷新应保留。
4. 再次修改同一事件，详情中的本机历史应增加一次；“复核记录”导出 CSV 应包含全部追加历史。
5. 将说明设为 `<img src=x onerror=alert(1)>`，页面应只显示原文本。说明以 `=1+1` 开头时，CSV 字段应带单引号前缀。
6. 在 390px 手机宽度下逐一访问五个视图，并测试导航、详情关闭及表格滚动。
